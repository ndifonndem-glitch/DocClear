Strategic Justification

The Three Winning Pillars: Why Next.js PWA?

Architectural Advantages Aligned with Real-World User Needs

⚡ 1. Zero-Friction Crisis Access
Users receiving urgent court summons, tenancy eviction notices, or high medical bills are in high cognitive distress. Forcing them to navigate an app store, enter credentials, and download an app causes 68% drop-off. A PWA opens instantly with full camera scanner capabilities.
🛡️ 2. NZ Privacy Act 2020 Compliance
Principle 12 requires data minimization and prevention of unauthorized storage. By utilizing ephemeral in-memory processing with no persistent disk database, sensitive user documents (IDs, payroll, health diagnoses) disappear immediately when the tab is closed or 'Start over' is clicked.
🔐 3. Co-located Secure BFF
Native mobile apps risk exposing API tokens via reverse engineering (APK decompilation). Next.js App Router keeps AI and OCR keys safely behind the server boundary (/api/analyse and /api/extract-doc), eliminating third-party reverse-engineering risks.
🎤 Speaker Script: "The definitive argument for Next.js PWA is user dignity and trust. A tenant facing a 48-hour eviction deadline needs immediate plain-language help, not an app store install prompt. By choosing a web-first PWA, we fulfill the New Zealand Privacy Act 2020 through ephemeral, zero-footprint processing, while keeping proprietary API keys securely encapsulated on the server."

Tutor Defense

Anticipated Questions & Defense Strategy

Prepared Academic Justifications for Class Discussion

Q1: "Why not use React Native with Expo to get a native app feel?"

Defense: React Native requires app store installation. For users facing urgent eviction notices or police letters, installation barriers cause severe attrition. Next.js PWA delivers 60fps responsiveness, full hardware camera access, and offline caching instantly via any browser.

Q2: "How do you protect sensitive legal or personal documents?"

Defense: We strictly follow the NZ Privacy Act 2020. Documents are processed ephemerally in RAM and are never written to a permanent database. Users can click 'Start over' at any time to purge all text and memory buffers immediately.

Q3: "What happens if a device lacks a camera or sensor permission is denied?"

Defense: Our UI follows graceful degradation. If `getUserMedia` fails or permissions are denied, the dashed file drag-and-drop zone remains active, supporting PDF, Word, text, and images with full OCR support.
